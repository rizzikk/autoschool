# Сервер автошколы (PocketBase)

Серверная часть итогового проекта: база данных, правила доступа по ролям, серверные проверки
занятий и тестовые данные. Версия PocketBase 0.40.x, Node.js 18 или новее нужен только для
служебных скриптов.

## Что здесь лежит

| Путь | Назначение |
|---|---|
| `pb_hooks/autoschool.pb.js` | обработчики PocketBase: проверки занятий, групп и справок, маршрут `/api/autoschool/busy` |
| `pb_hooks/lib/lessons.js` | правила занятия: длительность, категория, справка, пересечения по времени |
| `pb_hooks/lib/dates.js` | порядок дат в группах и справках |
| `tools/schema.mjs` | описание коллекций, полей, индексов и правил доступа |
| `tools/setup.mjs` | создаёт коллекции и заливает тестовые данные |
| `tools/seed.mjs` | тестовые данные: пользователи, курсанты, занятия, платежи |
| `tools/verify.mjs` | проверка сервера по сети: роли, правила, ошибки по полям, конфликты |
| `tools/export_sql.mjs` | строит `schema.sql` и `схема.md` из `pb_schema.json` |
| `pb_schema.json` | выгрузка схемы, импортируется в панели: Settings → Import collections |
| `schema.sql` | то же в виде SQL |
| `схема.md` | словарь данных и правила доступа |

## Запуск

1. Скачать PocketBase для своей системы с https://pocketbase.io/docs/ и распаковать.
2. Создать суперпользователя: `pocketbase superuser upsert root@autoschool.test Autoschool123!`
3. Запустить: `pocketbase serve --http=127.0.0.1:8090 --hooksDir=<путь к проекту>/pocketbase/pb_hooks`
4. В другом окне: `cd pocketbase/tools && node setup.mjs --reset`
5. Проверить: `node verify.mjs` (в конце строка «ИТОГО: успешно N, ошибок 0»).

Скрипт `setup.mjs` берёт адрес и учётную запись суперпользователя из переменных
`PB_URL`, `PB_SUPERUSER_EMAIL`, `PB_SUPERUSER_PASSWORD`; без них используются значения из примера выше.

## Роли и доступ

* Самостоятельно регистрируется только курсант. Учётные записи инструкторов и администраторов
  создаёт администратор.
* Администратор читает и меняет всё, физически удаляет записи.
* Инструктор видит курсантов, свои занятия, экзамены и справки, ведёт свои занятия и экзамены.
* Курсант видит только свои данные: профиль, занятия, экзамены, платежи, справку. Записывается
  на вождение и отменяет своё запланированное занятие.
* Удалённые «мягко» записи (`deleted = true`) скрыты правилами списка и просмотра от всех, кроме
  администратора.

Полные правила записаны в `pb_schema.json` и в `схема.md`.

## Серверные проверки занятия

Выполняются в `pb_hooks/lib/lessons.js` при создании и изменении занятия:

* длительность от 30 минут до 3 часов; ошибка у поля `ends_at`;
* категория автомобиля и инструктора совпадает с категорией курсанта;
* автомобиль в статусе «исправен»;
* у курсанта действует медицинская справка на день занятия;
* курсант записывает только себя, инструктор ведёт только свои занятия;
* курсант записывается не позднее чем за 30 минут до начала;
* инструктор, автомобиль и курсант не заняты другим занятием в это время: ответ 409 с указанием
  поля, к которому относится конфликт.

Ошибки полей возвращаются в формате PocketBase (`data.<поле>.code` и `message`), клиент
показывает их под соответствующими полями формы. Подробнее — в отчёте, раздел «Контракт API».

## Свободное время: `GET /api/autoschool/busy`

Нужен, чтобы курсант видел занятые интервалы, не имея права читать чужие занятия. Параметры:
`from`, `to` (обязательные, формат `2026-11-02 10:00:00.000Z`), `instructor`, `car`, `cadet`
(идентификаторы). Ответ: `{"items": [{id, starts_at, ends_at, instructor, car, cadet}]}`.
Нужен токен любого вошедшего пользователя.

## Размещение для работы по HTTPS

Опубликованное приложение работает по HTTPS, поэтому сервер тоже должен быть доступен по HTTPS,
иначе браузер заблокирует запросы. Подойдёт любой хостинг, где можно запустить один исполняемый
файл и сохранить каталог `pb_data`: виртуальный сервер с обратным прокси (Caddy, nginx) или
сервис вроде Fly.io и Railway. Каталог `pb_hooks` нужно положить рядом с файлом `pocketbase`.
Адрес сервера клиент берёт из параметра сборки:

```
flutter build web --release --dart-define=API_BASE_URL=https://ваш-сервер/api
```

В настройках PocketBase (Settings → Application) адрес публикации приложения добавляется в
список разрешённых источников, если сервер и приложение расположены на разных доменах.
