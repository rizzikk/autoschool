# Словарь данных автошколы

Файл построен из pb_schema.json скриптом tools/export_sql.mjs. Типы: «выбор» — одно из заданных значений, «связь» — ссылка на запись другой коллекции.

## users — Учётные записи

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| name | строка | нет | длина 0–255 |
| avatar | file | нет |  |
| role | выбор | да | значения: admin, instructor, cadet |

Индексы:

- CREATE UNIQUE INDEX idx_tokenKey__pb_users_auth_ ON users (tokenKey)
- CREATE UNIQUE INDEX idx_email__pb_users_auth_ ON users (email) WHERE email != ''

Правила доступа:

- список: `@request.auth.role = "admin" || id = @request.auth.id`
- просмотр: `@request.auth.role = "admin" || id = @request.auth.id`
- создание: `@request.body.role = "cadet" || @request.auth.role = "admin"`
- изменение: `@request.auth.role = "admin" || (id = @request.auth.id && @request.body.role:isset = false)`
- удаление: `@request.auth.role = "admin"`

## cadets — Курсанты

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| user | связь | да | ссылка на users |
| full_name | строка | да | длина 5–100 |
| birth_date | дата | да | дата и время UTC |
| phone | строка | да | шаблон ^\+7\d{10}$ |
| category | связь | да | ссылка на categories |
| status | выбор | да | значения: studying, graduated, expelled |
| enrolled_at | дата | да | дата и время UTC |
| deleted | логическое | нет |  |

Индексы:

- CREATE UNIQUE INDEX idx_cadets_user ON cadets (user)

Правила доступа:

- список: `@request.auth.role = "admin" || ((@request.auth.role = "instructor" || user = @request.auth.id) && deleted = false)`
- просмотр: `@request.auth.role = "admin" || ((@request.auth.role = "instructor" || user = @request.auth.id) && deleted = false)`
- создание: `@request.auth.role = "admin" || (@request.auth.role = "cadet" && @request.body.user = @request.auth.id && @request.body.status = "studying")`
- изменение: `@request.auth.role = "admin" || (user = @request.auth.id && @request.body.user:isset = false && @request.body.status:isset = false && @request.body.category:isset = false && @request.body.enrolled_at:isset = false && @request.body.deleted:isset = false)`
- удаление: `@request.auth.role = "admin"`
